name: work-issue
description: Execute a named issue through independent review and release readiness when the user says Work issue X or gives equivalent implementation authority.
---

Read `docs/AI_ISSUE_WORKFLOW.md`, `docs/AI_WORKFLOW_MODELS.md`, the original request,
issue record and relevant repository profile/source. A coordinator handoff is valid only
when it references verified equivalent Work authority and the established single-owner
lane. Follow that single procedure.
Explicitly delegate substantive design and independent review to the configured roles
in bounded contexts; verify dispatch rather than treating names as execution proof.
Resume existing contract, design and valid evidence. Work authority covers ordinary
corrections and safe validation. At positive stop, read `docs/AI_WORKFLOW_RELEASE.md`:
route automatically through Patch when a verified active standing owner grant covers
the exact candidate, procedure, targets and actions; otherwise await direct owner
authorization. Work authority or release readiness alone never authorizes release.
